# Human Labels 01: 人の目視ラベルと Claude・judge・機械判定の比較（2026-11-21）

Judge 01/02 のラベルはすべて Claude（AI）が付けた。judge の誤りと Claude のラベルの揺れを分けるため、プロジェクトの担当者（人、1 名）に 66 サンプルの目視ラベルを付けてもらった。

## 方法

- 対象 66 件
  - heldout-01 の 48 件すべて（Judge 02。Claude のラベルの揺れを測る）
  - Judge 01 で Claude のラベルと judge（diff-sil）が食い違った 18 件（どちらが人に近いかを見る）
- ラベル用のページ（claude.ai の artifact）で、1 件ずつ次を見せた
  - 動く GIF（`preview.gif`）
  - 元絵と 6 コマを並べた静止画
  - 動作の指示（「炎の形や明るさが揺らぐ。燭台・器・持ち手はそのまま」など）
- 選択肢は「使える / 使えない / わからない」。使えないときは理由（動きが違う・ほぼ動かない / 元絵が崩れる・消える・増える）、ほかに任意のメモ
- 由来（どの run か）、Claude のラベル、judge・機械判定の結果は見せていない。並びは動作ごと
- Claude との違い: 人は**動く GIF も見た**。Claude は静止画だけ
- 結果は各 run の `review.jsonl` に `reviewer: "human"` で追記した（Claude のラベルは `reviewer: "claude"`。`scripts/judge_agreement.py --reviewer` で選ぶ）

66 件中、使える 56、使えない 2、わからない 8。

- **使えない（2）:** heldout-01 のまばたきのウサギ 2 件（顔が崩れる。理由は「元絵が崩れる」）
- **わからない（8）:**

  |---|---|

  | ほぼ静止のハムスター | 「瞬きになっていない？」 |
  | 金の帯が消えるルビー | 「黄色いリング？みたいなものが消えている？」 |
  | 炎の色が変わる oil lamp | 「真ん中のものも炎？だとしたら問題ない」 |
  | くちばしが変わるペンギン（Pilot 03） | 「ちょっとぶれている」 |
  | 目が開いたままの猫 | メモなし |
  | 柴犬 | メモなし |
  | コーギー | メモなし |

### Claude のラベルとの一致（heldout-01、両方が判定した 38 件）

| | Claude: 使える | Claude: 使えない |
|---|---|---|
| 人: 使える | 20 | 16 |
| 人: 使えない | 0 | 2 |

一致は 38 件中 22 件（58%）。食い違った 16 件はすべて「Claude は使えない、人は使える」。Claude が落とした理由の内訳（括弧は件数）:

- 細部が消える（2）: コテージの煙突の赤い先端、柴犬の帽子
- 形が変わる（3）: 海賊旗のドクロ 2、機関車の上部
- 全体が明るくなる（2）: ダイヤ、エメラルド
- 泡に見えない（3）: ビーカー、フラスコ、薬瓶
- 炎の覆いが変わる（1）: oil lamp
- 新しいものが出る・変わる（2）: 旗の下端の青緑の画素、焚き火のきらめきが筋になる
- ほぼ静止・目が出たまま（3）: 旗、ハムスター、猫

人はこれらを、ループとして使えると判断した。

### Judge 01 で食い違った 18 件

## わかったこと

1 名・1 回の目視、66 件での観察。以下は今回の判定者・見せ方（人は動く GIF、Claude は静止画）での結果で、人一般の基準として一般化したものではない。

1. **今回の判定者の基準は、Claude の基準よりずっと緩かった。** 細部が消える、形や明るさが変わる、泡かどうか曖昧、といった変化を、人はループとして使えると判断した。人がはっきり使えないとしたのは、顔が崩れたものだけだった
2. **Judge 01/02 の調整と評価は、Claude の厳しい基準に合わせていた。** 今回の判定者のラベルでは diff-sil は使えるものの 6 割を落とし、ほぼ何でも通す v1 の方が人に近い
3. **今回の判定者のラベルでは、機械判定と judge は使えるものを多く落とした。** 機械判定は使えるものの 4 割近くを落とした。主な原因は `identity_drift` で、Pilot 03 で布の変形と相性が悪いとした旗のほか、宝石も落とした。人が使えないとしたのは 2 件だけなので、混入を防ぐことと使えるものを落とさないことのどちらを優先すべきかは、このデータでは評価していない
4. **今回の判定者にも、迷うものがあった。** ほぼ静止、目が出たまま戻らない、目立つ部品が消える。採用基準をはっきりさせる必要がある

## 注意

- 判定者は 1 名で、1 回だけ。人どうしの揺れは測っていない
- 人は動く GIF を見たが、Claude は静止画だけを見た。食い違いの一部は、見え方の違いによる可能性がある（細部の消失や形の変化は、動きの中では目立たないことがある）
- 人が使えないとしたのが 2 件だけなので、混入を防ぐ力はこのデータでは評価できない
- Judge 01 の 18 件は、食い違ったものだけを選んでいるので、全体の傾向を表すものではない

## その後（2026-11-22）

担当者が比較ページ（人・Claude・judge の判定を並べたもの）を見て、今回の人のラベルは緩めに付けたもので、Claude のラベルの方がおおむね正しいとした。採用基準は Claude のラベルに沿って `docs/acceptance.md` に書いた。ほぼ動かないものは落とす。以後の judge と機械判定の調整は、この基準のラベル（`--reviewer claude`）に合わせる。上の「わかったこと」2・3 の、人のラベルに基づく見方は採らない。

## 次の候補（当時）

- 採用基準を決める: 細部の消失・形の変化・ほぼ静止をどこまで許すかを文章にし、`docs/` に置く。judge の指示文と機械判定のしきい値は、その基準に合わせて見直す
- 人の基準に合わせるなら、機械判定のうち `identity_drift` の扱い（動作別のしきい値、または注記にとどめる）を、使えるものを落とさない方向に見直す
- 混入を防ぐ力を測るには、使えないものを多く含むサンプル（機械判定が reject・flagged にしたもの）にも人のラベルを付ける
