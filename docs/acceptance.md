# 採用基準

生成したループを学習データに採るかどうかの目視の基準。`review.jsonl` の `verdict`（`accept` / `reject` / `unsure`）はこの基準で付ける。judge の指示文と機械判定（`finalize.jsonl`）のしきい値は、この基準のラベルに合わせて調整する。

## 原則

**動作の指示が名指しした部分だけが動き、それ以外の元絵はそのまま残る**ものを採る。ループとして自然に見えるだけでは足りない。

- 動いてよい部分: 指示が名指しした部分（炎、湯気、煙、泡、きらめき、旗の布、まぶた、尻尾）。ただし動き方は決まっている（下の「動いてよい部分の範囲」）
- 動いてはいけない部分: それ以外（燭台・器・持ち手、旗竿、顔、胴体など）。形・色・明るさを保つ

## 使えない（`reject`）とするもの

次のどれか 1 つに当てはまれば使えない。

### 動き（`motion_matches = false`）

| 条件 | 例 |
|---|---|
| ほぼ動かない | 数画素しか変わらない、静止画に見える |
| 指示と明らかに違う動きになる | 泡の指示でハイライトが動くだけ、湯気の指示で黄色いきらめきが出る、フラスコに液体が満ちていく |
| まばたきが元に戻らない | 目が開いたまま、閉じたまま、元絵にない目が出て残る |

### 元絵（`drawing_kept = false`）

この基準の `drawing_kept` は、動いてはいけない部分が保たれていることに加えて、動いてよい部分が「動いてよい部分の範囲」に収まっていること（模様や輪郭を保つ、色相を変えない）も含む。今の judge の問い（`docs/pipeline.md`）は動く部分以外だけを問うので、下の表の最後の 2 行は judge が見逃しうる。judge の指示文はこの基準に合わせて見直す予定。

| 条件 | 例 |
|---|---|
| 目立つ部品が消える | マグのクッキー、フクロウの冠、煙突の赤い先端、金の帯、燃えさし |
| 動かない部分の形が変わる | くちばし、宝石が星形になる、機関車の上部 |
| 元絵にないものが出る | 下端の青緑の画素、黒い物体 |
| 動かない部分の色・明るさが変わる | 宝石や王冠の全体が明るくなる、頭の色が変わる |
| 顔が崩れる | 目が消える、口が開く、顔が溶ける |
| 動いてよい部分の上の模様や特徴的な形が崩れる | 旗の布がはためいて城の輪郭を失う、旗のドクロが別の形になる、布に新しい紋章が出る |
| 動いてよい部分の色が別の色に変わる | 炎が赤に変わる |

## 動いてよい部分の範囲

- 形・明るさ・濃さの揺らぎは許す（炎の明るさ、煙の濃さ、湯気の形、布のたわみ）
- 色は元の色の明暗の範囲で揺らいでよい。別の色相に変わるのは使えない
- 布や尻尾のように元絵で形を持つものは、たわんだり位置がずれたりしてよいが、上の模様や特徴的な輪郭（城の凹凸、ドクロ、紋章）は保つ

## 使える（`accept`）とするもの

次の両方を満たすもの（judge の `motion_matches` と `drawing_kept` が両方 true にあたる）。

- 指示した動作がはっきり起きている
- 変化が動いてよい部分とその範囲（上の節）に収まっている。動いてよい部分と接する輪郭の 1〜2 画素のぶれは許す

## わからない（`unsure`）とするもの

- 指示した動作かどうか判断できない（泡が立っているのか中身がちらつくだけか分からない、布が平らになるだけではためきか分からない、16×16 では目の変化がまばたきか分からない）。明らかに別の動きなら `reject`
- どこが動いてよい部分か元絵から決められない（例: 中央の部品が炎かどうか分からない oil lamp。人はこれを `unsure`、Claude は炎の色が赤に変わるとして `reject` にした）
- 変化が小さく、ほぼ静止かどうか判断がつかない

`unsure` は採用にも不採用にも数えず、評価（`scripts/judge_agreement.py`）からも外す。

## この基準の由来

- Judge 01/02（`docs/experiments/judge-01.md`, `judge-02.md`）で Claude が付けたラベル（`reviewer: "claude"`）を、担当者が比較ページで確認し、おおむね正しいとした（2026-11-22）
- Human Labels 01（`docs/experiments/human-labels-01.md`）の人のラベルは、担当者がこの基準より緩めに付けたもの。基準の調整には使わない
- 「ほぼ動かない」ものを落とすことは、担当者が決めた（2026-11-22）
